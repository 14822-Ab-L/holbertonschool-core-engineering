# Functions & Modularity

This directory contains Python exercises focused on functions, return values, and importing code between files.

## Topics

* Function definitions and parameters
* `return` values
* `print()` versus `return`
* ASCII conversion with `ord()` and `chr()`
* Loops and conditionals inside functions
* Python modules and imports
* Script execution and import behavior
* `__name__` and `if __name__ == "__main__"`

## Files and Description

| **File**              | **Description**                                                            |
| --------------------- | -------------------------------------------------------------------------- |
| `islower.py`          | Checks whether a character is a lowercase letter using ASCII logic.        |
| `uppercase.py`        | Prints a string in uppercase using ASCII conversion.                       |
| `print_last_digit.py` | Prints and returns the last digit of a number.                             |
| `pow.py`              | Calculates a number raised to a power using a loop.                        |
| `simple_add.py`       | Defines an addition function and demonstrates controlled script execution. |
| `test_import.py`      | Imports `simple_add` to demonstrate import behavior.                       |
| `add.py`              | Imports and uses an addition function from another file.                   |
| `calculation.py`      | Imports calculator functions and performs arithmetic operations.           |
| `variable_load.py`    | Imports and prints a variable from another file.                           |
