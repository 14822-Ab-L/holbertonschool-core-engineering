# Exception Handling

This directory contains Python exercises focused on handling runtime errors, catching exceptions, and writing safe and predictable functions.

## Topics

* `try` / `except` blocks
* Specific exception types
* Handling `TypeError`, `IndexError`, and `ZeroDivisionError`
* Using `else` and `finally`
* Raising exceptions
* Raising exceptions with custom messages
* Safe handling of invalid values and operations

## Files and Description

| **File**                      | **Description**                                                                    |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| `safe_print_list.py`          | Safely prints a specified number of elements from a list using exception handling. |
| `safe_print_integer.py`       | Safely prints an integer and returns whether the value was an integer.             |
| `safe_print_list_integers.py` | Prints integers from a list while skipping non-integer values.                     |
| `safe_print_division.py`      | Safely divides two integers and demonstrates `try` / `except` / `finally`.         |
| `raise_exception.py`          | Raises a `TypeError` exception.                                                    |
| `raise_exception_msg.py`      | Raises a `NameError` with a custom message.                                        |
