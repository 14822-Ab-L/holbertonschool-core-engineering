# Core Data Structures

This directory contains Python exercises focused on lists, tuples, sets, dictionaries, and working with collections of data.

## Topics

* Lists and list indexing
* Iterating through lists
* Replacing list elements
* Two-dimensional lists (matrices)
* Tuples and tuple operations
* Sets and common elements
* Dictionaries and key-value pairs
* Adding and updating dictionary values
* Finding values in dictionaries
* Handling invalid indexes and empty collections
* Formatted output

## Files and Description

| **File**                  | **Description**                                                  |
| ------------------------- | ---------------------------------------------------------------- |
| `print_list_integer.py`   | Prints all integers in a list, one integer per line.             |
| `element_at.py`           | Safely retrieves an element from a list using an index.          |
| `replace_in_list.py`      | Replaces an element in a list at a specific index.               |
| `print_matrix_integer.py` | Prints a matrix of integers with each row on its own line.       |
| `add_tuple.py`            | Adds the first two values of two tuples and returns a new tuple. |
| `common_elements.py`      | Returns a new set containing elements common to two sets.        |
| `update_dictionary.py`    | Adds or updates a key-value pair in a dictionary.                |
| `best_score.py`           | Returns the key with the biggest integer value in a dictionary.  |
