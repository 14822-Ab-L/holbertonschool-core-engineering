# Control Flow

This directory contains Python exercises focused on control flow and decision-making.

## Topics

* Conditional statements
* Comparison and Boolean operators
* `for` loops with `range()`
* `while` loops
* Numeric iteration
* Formatted output

## Files and Description

| File                      | Description                                                        |
| ------------------------- | ------------------------------------------------------------------ |
| `positive_or_negative.py` | Determines whether a random number is positive, zero, or negative. |
| `last_digit.py`           | Determines and evaluates the last digit of a random number.        |
| `print_alphabt.py`        | Prints the lowercase alphabet except for `q` and `e`.              |
| `print_hexa.py`           | Prints numbers from 0 to 98 in decimal and hexadecimal.            |
| `print_comb2.py`          | Prints numbers from 0 to 99 using two-digit formatting.            |
| `print_comb3.py`          | Prints unique combinations of two different digits from 0 to 9.    |
