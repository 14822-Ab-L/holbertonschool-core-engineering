# Python Advanced

This directory contains Python exercises focused on advanced programming concepts and practical file handling.

## Topics

- File input and output (I/O)
- Opening and closing files
- Reading file contents
- Reading files line by line
- Writing text to files
- Appending text to files
- File modes
- File cursor position
- UTF-8 text encoding
- Resource management with `with`
- File persistence

## Directories

| **Directory** | **Description** |
| ------------- | --------------- |
| `file_handling` | Introduces reading, writing, and appending text files, file modes, encoding, and resource management. |
