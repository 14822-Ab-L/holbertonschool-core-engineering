# Python File Handling

This directory contains Python exercises focused on reading, writing, and appending text files.

## Topics

- Opening files with `open()`
- Reading the full contents of a file
- Writing text to a file
- Appending text to a file
- File modes (`r`, `w`, and `a`) and their effects
- UTF-8 text encoding
- Managing file resources with the `with` statement
- Closing files safely
- File cursor position
- Returning character counts from write operations

## Files and Description

| **File** | **Description** |
|---|---|
| `read_file.py` | Defines `read_file(filename="")` to read a UTF-8 text file and print its contents to standard output. |
| `write_file.py` | Defines `write_file(filename="", text="")` to write UTF-8 text to a file and return the number of characters written. |
| `append_write.py` | Defines `append_write(filename="", text="")` to append UTF-8 text to a file and return the number of characters added. |
