# Abstract Classes & Interfaces

This directory contains Python exercises focused on abstract classes, interfaces, duck typing, multiple inheritance, mixins, and extending built-in classes.

## Topics

* Abstract classes
* Abstract methods
* `ABC` and `@abstractmethod`
* Interfaces
* Duck typing
* Multiple inheritance
* Method resolution order
* Mixins
* Extending built-in classes
* Overriding methods

## Files and Description

| **File**         | **Description**                                                                                      |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| `animals.py`     | Defines an abstract `Animal` class with `Dog` and `Cat` subclasses that implement `sound()`.         |
| `shapes.py`      | Defines abstract shapes and demonstrates duck typing with `Circle`, `Rectangle`, and `shape_info()`. |
| `flyingfish.py`  | Demonstrates multiple inheritance with `Fish`, `Bird`, and `FlyingFish` classes.                     |
| `dragon.py`      | Demonstrates mixins using `SwimMixin` and `FlyMixin` with a `Dragon` class.                          |
| `verboselist.py` | Extends the built-in `list` class with notifications for adding and removing items.                  |
