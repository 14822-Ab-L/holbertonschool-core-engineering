# Classes & Object Model

This directory contains Python exercises focused on object-oriented programming, classes, objects, attributes, methods, and basic encapsulation.

## Topics

* Classes and instances
* Creating objects
* Instance attributes
* The `__init__` method
* Private attributes
* Encapsulation
* Getters and setters using properties
* Input validation
* Instance methods
* Special methods such as `__str__`
* String representation of objects
* Modeling squares and rectangles

## Files and Description

| **File**         | **Description**                                                          |
| ---------------- | ------------------------------------------------------------------------ |
| `0-square.py`    | Defines an empty `Square` class and creates instances.                   |
| `1-square.py`    | Defines a `Square` class with a private `size` attribute.                |
| `2-square.py`    | Adds validation for the `Square` size attribute.                         |
| `3-square.py`    | Adds an `area()` method to calculate the square's area.                  |
| `4-square.py`    | Adds a property getter and setter for the square's size.                 |
| `5-square.py`    | Adds a `my_print()` method to display the square using `#` characters.   |
| `6-square.py`    | Adds position handling and a `__str__()` method for displaying a square. |
| `1-rectangle.py` | Defines a `Rectangle` class with validated width and height attributes.  |
| `2-rectangle.py` | Adds area and perimeter methods to the `Rectangle` class.                |
