# Python Object-Oriented Programming

This directory contains Python exercises focused on object-oriented programming and the Python object model.

## Topics

* Objects and instances
* Classes
* Instance attributes
* Instance methods
* Encapsulation
* Private attributes
* Properties, getters, and setters
* Input validation
* Special methods
* Object string representation
* Inheritance
* Parent and child classes
* Method overriding
* Polymorphism
* Class and object relationships

## Directories

| **Directory**              | **Description**                                                                                             |
| -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `classes_and_object_model` | Introduces Python objects, classes, attributes, methods, encapsulation, and object representation.          |
| `inheritance`              | Introduces inheritance, parent and child classes, method overriding, polymorphism, and class relationships. |
