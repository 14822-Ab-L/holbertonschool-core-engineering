# Python Object-Oriented Programming

This directory contains Python exercises focused on object-oriented programming and the Python object model.

## Topics

* Objects and instances
* Classes
* Instance attributes
* Instance methods
* Encapsulation
* Private attributes
* Properties, getters, and setters
* Input validation
* Special methods
* Object string representation
