# Inheritance & Polymorphism

This directory contains Python exercises focused on inheritance, parent and child classes, method overriding, polymorphism, and class relationships.

## Topics

* Inheritance
* Parent and child classes
* Subclasses
* Reusing inherited methods
* Method overriding
* Polymorphism
* `isinstance()`
* `issubclass()`
* Class hierarchies
* Modeling geometric shapes

## Files and Description

| **File**           | **Description**                                                           |
| ------------------ | ------------------------------------------------------------------------- |
| `base_geometry.py` | Defines a `BaseGeometry` class with area and integer validation methods.  |
| `1-rectangle.py`   | Defines a `Rectangle` class that inherits from `BaseGeometry`.            |
| `2-rectangle.py`   | Adds area calculation and string representation to the `Rectangle` class. |
| `1-square.py`      | Defines a `Square` class that inherits from `Rectangle`.                  |
| `2-square.py`      | Adds string representation to the `Square` class.                         |
